# Q4 今晚模型与代码改进报告

日期：2026年8月9日

## 一、改进目的

今晚主要针对问题4的三个问题进行修正：一是严格混合候选没有完整覆盖快速搜索得到的含B跨线点；二是纯A方案在Q3、Q4之间存在重复计算和随机序列口径不统一；三是原有检查点、并行运行和多候选统计判定仍不够稳健。

本次工作的重点不是单纯增加蒙特卡洛次数，而是先统一模型口径、补全候选集合，再用固定样本量完成正式验证。

## 二、核心模型改进

### 1. 补全含B临界候选

重新核对 `question4_boundary.csv` 和 `question4_verify.csv` 后发现，快速验证带共有6个含B跨线点：

\[
(609,5),(608,14),(610,4),(611,3),(610,12),(609,21).
\]

原严格候选集遗漏了 \((611,3)\) 和 \((609,21)\)。新版模型补齐这两个点，并加入低成本搜索点 \((598,62)\) 与邻近对照点 \((617,1)\)，最终严格复核8个含B候选。

### 2. 纯A与混合候选分工

纯A方案不再在Q4中重复抽样，而是直接引用Q3的 \(M=10000\)、32边严格实体夹逼结果。统一保守基准为

\[
(N_A,N_B)=(619,0).
\]

Q4只检验含B方案能否以更低成本可靠替代该纯A基准。这样既减少重复计算，也避免Q4的小样本结果覆盖Q3的正式结论。

### 3. 统一随机序列

每个随机种子固定先生成750根A，再按候选数量截取前缀。这样Q4纯A退化情形与Q3使用相同的随机数消耗顺序，保证“相同种子”确实对应相同微构体，而不是仅种子编号相同、方向和长度序列实际错位。

### 4. 严格实体几何夹逼

- A采用32边内接、外切多棱柱；
- B采用三级细分二十面体的内接、外切多面体；
- 周期片段先平移，再与基本盒进行实体裁剪；
- 同源周期片段作为独立图节点，不自动电连接；
- A-A、A-B、B-B接触采用AABB预筛、安全解析界与凸体GJK距离；
- 每个样本均检查“内界导通不强于外界导通”。

### 5. 多候选联合置信判定

正式样本量在运行前固定为 \(M=4000\)，避免根据中途结果选择停止时点。8个候选各有内界、外界两个概率参数，因此共对16个区间采用Bonferroni联合校正：

\[
\alpha_{\mathrm{each}}=\frac{0.05}{16}=0.003125.
\]

判定规则为：

- 内界联合下限不低于0.90：可靠可行；
- 外界联合上限低于0.90：可靠不足；
- 其他情况：待定。

逐点95% Wilson区间用于展示单点证据，Bonferroni联合区间用于从多个候选中作正式选择。

## 三、代码与运行稳定性改进

1. 对明显接触或明显分离的A-A介质使用安全解析界，只让临界窄带进入GJK，减少几何计算量。
2. 增加Windows处理器亲和性和BelowNormal优先级控制，正式运行峰值CPU保持在约90%以内。
3. 检查点改为紧凑JSON、临时文件写入后原子替换，并保留上一版 `.bak`；主文件损坏时可自动回退。
4. 增加 `--status` 参数，可只查看检查点进度而不启动模拟。
5. 旧11点、\(M=300\) 结果重命名为探索版，避免被误当成正式结果。
6. 自动测试增至69项，覆盖随机序列、周期几何、内外夹逼、联合置信、候选完整性、检查点恢复和结果文件写入。

## 五、对后续优化的判断

本次结果说明，继续把样本量从4000提高到10000未必是最优方向。例如 \((617,1)\) 的内界概率为0.89675、外界概率为0.90300，几何夹逼本身已经跨越0.90。即使统计区间继续缩小，当前几何分辨率下仍可能无法确定其真实状态。

因此后续优先级建议为：

1. 对7个待定点提高几何分辨率，尤其是 \((617,1)\)，可增加A多棱柱边数或B细分级数；
2. 若要证明全局最优，对619根A成本以下的非支配边界进行严格外界粗扫描，防止快速近似搜索遗漏候选；
3. 再根据几何敏感性结果决定是否需要追加样本，而不是直接把全部候选增加到10000次；
4. 最终论文继续采用“当前证据支持纯A保守推荐，但含B全局最优性尚未严格证明”的表述。
