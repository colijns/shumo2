# ADR-0001：问题1 固定使用 wrap_crossings=False（附件端点按原值）

- 状态：accepted
- 日期：2026-08-07
- 相关文件：`Q1/core.py`（`analyze_group` / `electrode_contact` 的 `wrap_crossings` 参数）

## 背景

题目"相关说明 2"给出**边界截断规则**：介质越界部分沿越界方向反方向平移一个边长 L=10000 nm，从相对侧重新进入微构体。该规则对随机生成、可能完整越界的介质（问题 2/3/4）是必要的。

附件（问题 1）给出的是**已经生成好的原始介质记录**，规格 `docs/问题1.md` §2 定稿口径明确：

- 附件每一行对应一个生成前的原始介质 A，具有唯一节点编号 A1…；
- 该行前 3 列与后 3 列坐标按原值作为圆柱轴线两端点，**不足 5000 nm 的记录不擅自补长**；
- 周期镜像只用于计算周期最短距离，不把镜像重新编号为新的介质；
- 附件中的不同行不能只因同时位于相对边界就直接合并，仍需通过周期距离判定是否接触。

## 决策

`analyze_group(c, u, h, wrap_crossings=False)` 恒为问题 1 的唯一合法口径：

1. 附件端点按原值使用，半长 h = ‖p2 − p1‖/2（不再推断该行存在"未显示的越界部分"）；
2. 周期镜像 27 个平移只进入介质间距离计算；
3. 电极接触判定只依据圆柱在 x 方向的实际投影范围（x_min ≤ −5000+δ 连左，x_max ≥ 5000−δ 连右），一行至多接一个电极；
4. `wrap_crossings=True` 分支保留接口但抛 `NotImplementedError`，防止问题 1 中误用（接口留给后续随机仿真实现完整越界圆柱的截断语义）。

## 理由

- 附件轴线长度统计：组1/组2/组3 分别有 2/11/155 条记录长度为 5000 nm，其余均不足 5000（最短 525.7 nm）。若用标称长度 5000 覆盖端点（补长），会改变几何关系与接触结论。
- 关键证据：组1 的导电路径 A1—A12 依赖 A12 的镜像 (k=−10000,0,0) 与 A1 左端点零距离重合；该几何关系来自附件原值，与补长无关，但任何"自动推断越界部分"的启发式都可能引入假接触。
- 与后续问题的一致性：问题 2/3/4 随机仿真生成完整越界圆柱时采用 True 口径，但必须复用同一套几何接触内核（`gjk_distance` / `analyze_group`）。

## 后果

- 正面：附件复算结果确定、可复现（5/39/344 条接触边、三组均导电）；与文档 §11/§13 全部数字一致。
- 代价：随机仿真（后续问题）需要再实现 True 分支的真实截断语义（同一根完整圆柱可能被截成跨左右电极的两个片段，图中按一个节点处理时电极接触需按片段分别判定）。
- 附件全部端点已校验位于 [-5000,5000]（`load_cylinders` 检查），不存在需要截断的越界记录；若后续发现例外，需回到本 ADR 重新评审，而不是直接改问题 1 代码。
