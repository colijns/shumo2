## 使用注意

- **图内无标题**：按论文规范，图题写在正文 caption 中，图内仅保留 Case 标注与图例（fig9 图例左下、fig10 图例整图底部、fig11 各子图图例）。
- **数值口径（重要）**：本目录数值一律以报告为准——Q3 四算例总飞行距离 **1575.654 / 643.850 / 1941.696 / 1353.347 km**、$S_{\max}$ **8.682 / 11.668 / 9.418 / 9.972 h**、总必要等待 **0 / 85 / 0 / 195 s**（Case2 的 85 s = 40 s + 45 s 两段边界整定等待，对应报告 §4.3）。fig11 基线统一为"**问题 2 无禁飞区方案**"（Q2 正式档案 `enhanced_run_20260817_e2000/q2/strict/`）：$S_{\max}$ 基线 8.682 / 7.516 / 8.140 / 8.377 h（增幅 +0.0% / +55.2% / +15.7% / +19.0%），距离基线由 task_routes 欧氏重建 1556.771 / 187.926 / 1588.013 / 1005.977 km（增幅 +1.2% / +242.6% / +22.3% / +34.5%）。**勿引用旧口径**：以问题1 为基准的 +2.1% / +243.4% / +22.4% / +34.9%、Case2 增幅 +255.6%、Case3 +35.0%、Case3 等待 1342 s、Case2 非直飞段 12 个——均为旧档案数值，与当前图面及报告不符。
- **fig9 语义**：detour/visibility 段画**真实绕行路径**（切点直线 + 沿禁飞区圆边弧线，由求解器同款几何重建），而非起终点直线——解档案只存起终点，其直线弦恰好穿过禁飞区圆（几何验证 d=3.1~43.3 < r），直线画法会造成"红线穿禁飞区"的物理矛盾；重建长度与解档案 distance_km 逐段一致（差 ≤ 0.001 km），路径不进入任何禁飞区（构造半径 = 管制半径 + 10 m 安全裕度）。direct/wait_direct 段保持直线（飞行时刻与禁飞窗不冲突，等待后直飞段已等禁区解除）。现存多圆绕行在 Z4/Z3：134→66 可见图段 affected_zones 为 Z4/Z3（同窗 10:30–11:30 生效、按并集避让），绕 Z4 安全圆边弧线直接见于主图（"切线-安全圆弧-切线"几何）。Z1/Z2 虽为空间相交且同时生效的圆对，聚焦轮后其并集穿越段已被消除（改走直飞/等待后直飞）。
- **fig10 语义**：浅蓝块=任务执行时段（飞行段与巡检作业合并——小时级横轴下 300 s 巡检只是细竖条噪音，"作业/等待/禁飞"三层区分已足够支撑"禁飞触发等待/绕行"论证；块内深蓝细竖线=各巡检作业时刻，保留整块感同时体现多巡检点串联节奏，Case2 任务密集区竖线密集、稀疏区段一目了然）；各无人机时间线互不重叠冲突；Case2 两段等待均为禁飞区边界时刻触发的**边界整定等待**（40 s / 45 s，非人为加时——红色虚线自等待块起点连至禁飞带顶部边缘，直观呈现"等待起始点落在禁飞窗内、等禁区解除再出发"）；Case3 零等待（聚焦轮经任务重排彻底消化，禁飞带淡化+角注"无等待"结论）；Case4 的 195 s 为 Z4 失效边界整定。禁飞时段背景带跨全部无人机行，**单区/重叠区深浅两档**（重叠区即多圆并集时段加深，如 Case2 的 10:30–11:30 与 15:00–17:00）、顶部边缘 Zone 编号、时间窗入图注——各算例 Zone 编号与时间窗不同（自 8:00 起）：Case1 Z2 11:30–13:30 / Z3 13:30–15:30 / Z1 14:30–17:00；Case2 Z4 09:00–11:30 / Z3 10:30–13:00 / Z2 14:30–17:00 / Z1 15:00–17:00；Case3 Z5 09:00–11:00 / Z4 10:00–12:30 / Z1 11:00–13:30 / Z6 11:30–14:00 / Z3 12:00–14:30 / Z2 15:30–17:00；Case4 Z5 08:30–10:30 / Z4 10:30–12:30 / Z7 11:00–13:30 / Z3 12:00–14:30 / Z1 14:00–16:00 / Z6 14:30–16:30 / Z2 16:00–17:00（Z8 为零时长单点窗口，不渲染）。每行右端单机完成时刻标注直接可读负载均衡（与报告 δ 指标呼应）；横轴浅灰细虚线为禁飞区起止时刻锚点。直观对应"无人机不进入管制区"硬约束。
- **fig11 语义**：上两组增幅以问题2 为基准（无禁飞区方案引入禁飞约束后的代价）；**Case2 增幅最大（+242.6%）**——4 个禁飞区（Z1~Z4，半径 5.0~6.1 km）互相重叠形成沿任务走廊的连续禁飞带，阻断主走廊；Case1 增幅最小（+1.2%，禁飞约束名义生效、实际空转）；$S_{\max}$ 维度 Case2 增幅 +55.2% 亦为最大（2 架机群 + 禁飞夹缝完成 139 任务）；下子图总必要等待 0 / 85 / 0 / 195 s 与论文表4 一致（Case2 的 85 s = 40 s + 45 s 边界整定等待、Case4 的 195 s 为 Z4 失效边界整定），是"时间代价"维度的补充。
