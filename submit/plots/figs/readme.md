## 再生成方法

```bash
conda activate math
python plots/plot_overview.py   # 图1、图2
python plots/plot_summary.py    # 图12
```

脚本会重绘并覆盖本目录文件（图1/图2 不依赖求解器，秒级；图12 直接读三问解档案）。

## 使用注意

- **图内无标题**：按论文规范，图题写在正文 caption 中，图内仅保留 Case 标注与图例（fig1 子图左上 Case 标签 + 底部共享图例、fig2 左上图例、fig12 各子图右上图例）。
- **数值口径（重要）**：
  - fig12 的 Q3 侧数值为 **2026-08-18 冲突聚焦轮后正式档案** `outputs/workbooks/q3/strict/Case*.json`（fleet_size / metrics.S_max_s / metrics.delta_s）；Q2 侧为最终档案 `enhanced_run_20260817_e2000/q2/strict/Case*.json`（fleet_size / metrics.Tmax_s / metrics.delta_s——报告表3 依据）。**勿用 `outputs/workbooks/q2/strict/`**（过时档案）。
  - 三问 N（架）一致：**4 / 2 / 5 / 4**（方案约束下数量稳定）。
  - T_max（h）：Case1 **8.682 / 8.682 / 8.682**；Case2 **7.519 / 7.516 / 11.668**；Case3 **8.149 / 8.140 / 9.418**；Case4 **8.381 / 8.377 / 9.972**（问题3 即 S_max）。
  - δ（h）：Case1 **0.463 / 0.176 / 0.028**；Case2 **0.024 / 0.011 / 0.000**；Case3 **0.129 / 0.076 / 0.039**；Case4 **0.055 / 0.016 / 0.014**（问题3 记为 Δ；fig12 图面以 min 显示：27.8/10.5/1.7、1.4/0.7/0.0、7.7/4.5/2.3、3.3/1.0/0.8，1 位小数）。
- **fig12 语义**：上子图 (a) 最长完成时间——**口径说明**：问题1/2 为工作时长 $T_{max}$、问题3 为含等待的完成时刻 $S_{max}$（图内统一标注"最长完成时间 (h)"，两者在各自定义下即"系统最长完成时间"，口径差异须在正文/图注交代）；黑色虚线 9 h 处为**「原 9 小时时限（问题1 约束）」**——问题1 单机上限 32400 s = 9 h，问题3 不继承该时限：Case2/3/4 问题3 柱均超出该线（Case2 升至 11.67 h、+55.2% 为最），直观呼应报告 §模型假设；Case1 增幅 +0.0%（禁飞约束名义生效、实际空转）。下子图 (b) 工作时长极差 δ (min)——逐问收窄体现两轮均衡优化收益（Case1 27.8 → 10.5 → 1.7 min，降幅 −62% / −94%；Case2 问题3 完全均衡 δ=0，金色星标"★ 完全均衡（δ=0）"+ "vs Q1 -100%"）；问题2 侧 δ 已较问题1 大幅收窄（问题1 "时间最短"单目标下的天然失衡被问题2 均衡目标修正）。**计算基准**：上子图红色增幅以问题2 为基准（标注上标 ¹）、下子图绿色降幅以问题1 为基准（上标 ²）——基准说明以脚注行置于整图底部，勿手工混算。N（4/2/5/4 架）三问一致已在图面移除，改由正文表述。
- **数据源**：图1/图2 读 `attachment/附件1.xlsx`（坐标单位 1 单位 = 100 m，I/II/III 级展开 3/2/1 任务）；图12 读三问正式档案（见上，Q1 侧为 `outputs/workbooks/q1_solution_Case*.json`：N / Tmax_s / Tmin_s）。
- 留存池：本目录文件与 `docs/appendix/figures/` 保持同步（改动后须复制过去），图配套信息见 `docs/appendix/figure_notes.md` 图1、图2、图12 节。
