## 使用注意

- **图内无标题**：按论文规范，图题写在正文 caption 中，图内仅保留左上/右上角 Case 标注与必要的图例。
- **读取顺序**：fig3（方案展示）→ fig4（均衡性分析）→ fig5（求解可信度），构成问题1 结果部分完整证据链。
- **fig5 语义**：图题建议"固定机群下局部搜索验证曲线"（或"目标值 best-so-far 包络图"）——本图语义为局部搜索对构造初始解的**验证**而非"收敛优化过程"：Case1/3/4 热启动初始解即最优（0 次改进，曲线自 t=0 水平），Case2 在第 57 s 完成唯一一次改进（幅度约 0.03 h）；淡灰带表示搜索仍在尝试（被拒绝的移动未改善目标）；正文应表述为"初始解质量验证"，不宜写"目标值随搜索时间快速下降"。**纵轴为求解器目标 f=Σt_k+T_max（总工时+最大单机工时），非 T_max 本身**（已验证 objective 与档案 sum(work_s)+T_max_s 精确一致）；图注须写明 f 定义，避免评审误读纵轴量级（22~49 h）与报告 T_max（8~9 h）不一致。纵轴以最终最优值为基准收紧 ±3%（最优值红线居中，灰带仅作淡背景）；收敛日志仅覆盖 0~300 s，未画 1800 s 延伸。
- 留存池：本目录文件与 `docs/appendix/figures/` 保持同步（改动后须复制过去），图配套信息见 `docs/appendix/figure_notes.md` 图3~图5 节。
