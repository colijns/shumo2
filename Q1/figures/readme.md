## 图例释义

- 黄色粗线：见证导电路径上的介质 A（轴线表示，实际半径 30 nm 相对微构体边长 10000 nm 不可见）
- 红色粗线：路径接触边
- 灰色细线：其余介质（组3 按密度淡化，极淡者为孤立介质；3D 面板中较亮灰为网络参与体）
- 黑色细线：其余接触边
- 半透明黄色面（3D）/ 淡黄竖带（2D）：左右带电面（x=±5000 nm）
- (b) 面板黄色圆点（白描边）+ 编号：路径节点介质；红点 S/T：路径与左右带电面的端点

## 坐标轴

- (a) 3D 面板：x、y、z 轴——空间坐标（nm），原点为微构体中心
- (b) 2D 面板：x、z 轴——空间坐标（nm），x–z 平面投影（沿 y 方向观察，完整展开组3 路径的 z 向走向）
