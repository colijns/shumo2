## 使用注意

- **图内无标题**：按论文规范，图题写在正文 caption 中，图内仅保留 Case 标注与图例（fig6 图例在顶部一行、fig7 图例在上子图左下）。
- **数值口径（重要）**：本目录数值一律以报告表3 为准——Case1 的 δ 由 **0.4633 h（27.8 min）降至 0.1756 h（10.5 min）**，相对降幅 **−62.1%**，T_max 保持 31255 s 完全不变（+0.0%）。早期版本曾使用过时档案（outputs/workbooks/q2/strict/，δ=807 s、降幅 −51.6%），与报告不一致属硬伤，现已改读最终档案 `enhanced_run_20260817_e2000/q2/strict/` 并统一。
- **fig6 语义**：任务在路线间交换而非单向搬移（四机任务数 16/27/11/18 全不变）——UAV2（基线最闲 29587 s）换入飞行时间更长的任务（→30623 s，+17.3 min），UAV4 换出（30977→30800 s，−3.0 min），UAV1/UAV3 完全不动（灰色弱化）；均衡调整仅发生在 UAV2 与 UAV4 之间。δ 由 1668 s 收窄至 632 s，是改善的直接来源。
- **fig7 语义**：问题2 采用先保 T_max 不劣化、再压 δ 的两阶段（ε-约束）策略——上子图箭头方向即帕累托改进方向（T_max 不升、δ 大幅下降）；下子图相对变化率为"以问题1 为基准"的变化率（δ 条 −62.1% 为负向条，T_max 条高为 0 故以文本标注零代价）。**下子图仅表达相对变化率，具体绝对数值见报告表3 与图6**。
- **fig8 语义与阅读顺序**：图8 是"总"——先给四算例全部均衡改善的整体结论，再由图6/图7 对 Case1 做"分"的深入拆解，符合"总-分"阅读逻辑。**降幅排序为 Case4（−71.4%）> Case1（−62.1%）> Case2（−51.8%）> Case3（−41.3%）**，不是 Case1 最大——Case4 初始方案已较均衡（δ 仅占 T_max 的 0.7%）仍进一步收窄极差；柱顶标注为相对降幅（以问题1 为基准），柱高为 δ 绝对值（min）。
- **数据源**：Q1 侧 `outputs/workbooks/q1_solution_Case1.json`（uavs[].work_s、Tmax_s/Tmin_s）；Q2 侧 `enhanced_run_20260817_e2000/q2/strict/Case1.json`（metrics.route_work_s、delta_s，报告表3 依据）。不要改回 `outputs/workbooks/q2/strict/`——该目录为过时档案。
- 留存池：本目录文件与 `docs/appendix/figures/` 保持同步（改动后须复制过去），图配套信息见 `docs/appendix/figure_notes.md` 图6、图7 节。
