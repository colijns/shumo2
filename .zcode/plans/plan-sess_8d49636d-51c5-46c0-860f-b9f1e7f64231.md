# 问题1 实现计划（终版）：OR-Tools 两阶段求解 min-max mTSP

## 已敲定的决策（grill 结论）

求解器 = pip 安装 ortools；时间预算 = 阶段1每候选 120 s + 阶段2 300 s；本轮只出数值结果（路线图下轮从解档案生成）。数据事实已核对：任务数 72/139/140/182 吻合；官方模板列名 `UAV ID` / `1th Inspection Point`…照抄。

## 风险应对（全部落实）

**风险1（相邻约束爆炸）——经核算前提不成立，改为机器可验证的防护**：合同指定只对同 Point_ID 任务对加约束，单点任务数 ≤3 → 单点有序对 ≤6，四算例约束总数为 50/100/100/130（O(n_I+n_II) 线性，非平方）。"上万条"只对应 all-pairs 误实现。防护：① 期望约束数 50/100/100/130 写死为硬断言，不符立即 fail fast；② 约束条数+建模耗时逐算例落日志，>5000 告警；③ 正式运行前先对 Case4 做 30 s 冒烟测试（报告建模耗时/约束数/可行性），实测过关再全量。

**风险2（无随机种子）——解档案锚定**：① 每算例最终解落盘 `outputs/workbooks/q1_solution_Case{X}.json`（任务序列、N、Tmax、Tmin、参数快照），表2 数字由档案复算；② `--verify` 纯重放模式：不调求解器，从 JSON+原始数据复算全部指标出报告，任何机器可复现；③ 固定全部可固定参数，代码头注释与 ADR 如实声明"启发式解"。

**风险3（下界兜底）**：双下界取 max——MST 下界 `ceil((M/12+L_MST/55)/9)` 与纯服务量下界 `ceil(M·300/32400)`，均入日志；单点可达性不通过 → 抛 `InfeasiblePointError`（含点 ID/往返耗时），该算例标 `INFEASIBLE_DATA` 后继续其余算例；阶段1 递增设帽 N_LB+6，耗尽标 `NO_FEASIBLE_FOUND`；仅 N_feasible=N_LB 标 PROVEN_BY_LOWER_BOUND，否则 BEST_FEASIBLE_NOT_PROVEN。

**风险4（日志/续跑）**：`logging` 双输出（控制台 + `Q1/logs/solve_q1_<ts>.log`），逐轮记录算例/N/阶段/预算/可行与否/目标值/耗时；AtSolutionCallback 收敛曲线存 `Q1/logs/convergence_Case{X}.csv`（无该 API 则降级记起止两点）；每算例解完即写 JSON 检查点，`--resume` 跳过已完成算例。

**风险5（校验报告）**：六项检查输出 `q1_verification_report.{json,md}`，每条违规含算例/无人机 ID/类型（MISSING_VISIT、EXTRA_VISIT、ADJACENT_DUPLICATE、TIME_OVERFLOW、ROUTE_NOT_CLOSED、MISMATCH）/定位细节；失败时中间解已留存（配合 --resume 免全量重跑），非零码退出。

## 实施步骤

1. **装依赖**：math 环境 `pip install ortools`，打印版本；`requirements.txt` 追加。
2. **写 `Q1/solve_q1.py`**：数据层（load_table 读四 sheet，I/II/III 展开 3/2/1 任务）→ 矩阵层（d=0.1×欧氏 km，c=ceil(3600d/55) 秒，服务 300 s，上限 32400 s）→ 双下界 + 可达性异常 → OR-Tools（时间维度 capacity=32400/slack=0/起点 cumul=0，弧成本=飞行秒，GlobalSpanCostCoefficient=1，任务全必访，同点有序对 NextVar 约束+硬断言，PCI+GLS）→ 两阶段驱动（120 s/档递增至 N_LB+6，固定 N 后 300 s）→ 结构化校验器 + `--verify`/`--resume` → 输出（官方列名、无人机 1 起、短行留空；解 JSON 档案）。
3. **冒烟**：Case4 短预算 30 s，核对建模耗时/约束数（应为 130）/可行解存在。
4. **全量运行**：后台 `PYTHONIOENCODING=utf-8 <math python> Q1/solve_q1.py`，约 30–45 min；跑完 `--verify` 重放出报告；汇报四算例 N/Tmax/Tmin 与最优性标记。
5. **文档沉淀**：CONTEXT.md 术语表；docs/adr/0001（选型取舍 + 无种子→档案锚定复现策略）。
6. **附录留存**：源码与结果拷入 `docs/appendix/source_code/Q1/`。
